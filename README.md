# Customer Support AI Agent

An AI-powered customer support agent that uses customer-specific
memory to provide more contextual and personalized support responses.

---

## Project Goal

The goal of this project is to create a customer support agent that
can:

- Understand customer queries
- Retrieve relevant customer-specific memories
- Use those memories when generating responses
- Store useful conversation information
- Use available context during future interactions
- Display recalled memories to the support user

The core idea is:

```text
Customer
   ↓
Conversation
   ↓
Memory
   ↓
Future Conversation
   ↓
Relevant Memory Retrieval
   ↓
Context-Aware AI Response
